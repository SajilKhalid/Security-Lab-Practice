# Security Lab Practice

## Overview

This repository documents hands-on cybersecurity labs completed while preparing for the CompTIA Security+ (SY0-701) certification. Each lab captures the procedures followed, screenshots, findings, documentation, and key takeaways from the exercise.

It serves as a growing cybersecurity portfolio that demonstrates practical security skills through applied lab work.

## Topics Covered

- Fundamental security concepts
- Threats and attack techniques
- Cryptography
- Identity and access management
- Network security
- Cloud and virtualization
- Resilience and data protection
- Vulnerability management
- Endpoint and system hardening
- Incident response and forensics
- Malware analysis
- Governance and automation
- Offensive security and penetration testing
