### SIEM Threat Investigation & Incident Analysis

**Tools:** Wazuh, OpenSearch, Sysmon, PowerShell, CyberChef, Linux, jq, MITRE ATT&CK

Conducted a simulated SOC investigation involving suspicious executable creation, encoded PowerShell activity, and scheduled task persistence.

- Investigated and prioritized high-severity SIEM alerts.
- Analyzed endpoint telemetry and process relationships.
- Decoded obfuscated PowerShell commands.
- Identified potential indicators of compromise and persistence mechanisms.

- Developed incident response and detection recommendations.
